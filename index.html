1. Binary Molecular (2 non-metals)

First element full name. Second = root + -ide. Greek prefixes for counts. Never mono- for first element. Drop a/o before oxygen: monoxide dioxide trioxide tetroxide pentoxide hexoxide heptoxide octoxide nonoxide decoxide. If O + halogen, halogen first (e.g. Cl₂O₇ = dichlorine heptoxide). Diatomics H₂ O₂ F₂ Br₂ I₂ N₂ Cl₂ standalone = element + gas (chlorine gas). Common: NH₃ ammonia, H₂O water, CH₄ methane, C₂H₆ ethane, C₃H₈ propane, N₂O nitrous oxide.

2. Binary Ionic + Multivalent

Metal first + non-metal -ide. Criss-cross, reduce to lowest ratio. Stock: Roman numeral charge, e.g. tin(IV) sulfide. Classical: lower = -ous, higher = -ic.

3. Polyatomics & Oxyanions

NH₄⁺ ammonium, OH⁻ hydroxide, acetate C₂H₃O₂⁻/CH₃COO⁻. Parents (-ate): NO₃⁻ nitrate, FO₃⁻ fluorate, ClO₃⁻ chlorate, BrO₃⁻ bromate, IO₃⁻ iodate, CO₃²⁻ carbonate, SO₄²⁻ sulfate, PO₄³⁻ phosphate. +1 O = per-ate (ClO₄⁻ perchlorate), -1 O = -ite (ClO₂⁻ chlorite), -2 O = hypo-ite (ClO⁻ hypochlorite). Same for Br/I/F. H-removal makes charge 1 more negative. HCO₃⁻ bicarbonate/hydrogen carbonate, HSO₄⁻ bisulfate/hydrogen sulfate, H₂PO₄⁻ dihydrogen phosphate, HPO₄²⁻ hydrogen phosphate. Bi- only when 2- + H → 1-.

4. Acids & Bases

Bases = cation + OH⁻ (calcium hydroxide Ca(OH)₂). Binary acids (no O, aq): hydro-root-ic acid: HF(aq) hydrofluoric, HCl hydrochloric, HI hydroiodic, H₂S(aq) hydrosulfuric, H₃P(aq) hydrophosphoric. Gas (g) = covalent name (H₂S(g) hydrogen sulfide). Oxyacids: per-ate→per-ic, ate→ic, ite→ous, hypo-ite→hypo-ous. E.g. HClO₄ perchloric, HClO₃ chloric, HClO₂ chlorous, HClO hypochlorous.

5. Peroxides & Hydrates

Peroxide ion O₂²⁻ (extra O vs oxide). Never reduce: Na₂O₂ sodium peroxide, BaO₂ barium peroxide, H₂O₂ hydrogen peroxide, K₂O₂ potassium peroxide. Hydrates: ionic name + prefix-hydrate: CaCl₂·2H₂O calcium chloride dihydrate, Na₂CO₃·10H₂O sodium carbonate decahydrate. Anhydrous = after water evaporated.

6. Organic

Alkanes CₙH₂ₙ₊₂ -ane: methane CH₄, ethane C₂H₆, propane C₃H₈, butane C₄H₁₀, pentane C₅H₁₂, hexane C₆H₁₄, heptane C₇H₁₆, octane C₈H₁₈, nonane C₉H₂₀, decane C₁₀H₂₂. Branched: 1) longest chain parent, 2) number for lowest substituents, 3) alphabetical -yl (di/tri ignored), 4) dashes number-letter, commas number-number. Alkenes -ene double, alkynes -yne triple (linear, drawn straight). Double/triple in longest chain, gets lowest number over alkyl. Cyclo-: cyclopentane, cyclohexane; one group no number (methylcyclohexane); multi = lowest combo alphabetical. Benzene C₆H₆ alternating doubles; substituents as prefixes (ethylbenzene, 1,4-diethylbenzene para).
